# Report Mapping

How each piece of professor feedback maps to a deliverable in this project.

## Feedback to Deliverable

| Professor's feedback | What addresses it | Where to find it |
|---|---|---|
| "Lacks practical simulator verification" | 62 pytest tests (hand-derived expected values traced on paper), invariant checks, performance benchmarks | `tests/test_policies.py`, UI → Verification page, hand-verified badges on each policy |
| "Lacks manual tracing" | Step-by-step manual tracing guide with 6 blank worksheets (3 ARC, 3 LIRS), answer key generated by the simulator, interactive step-through in the UI | `docs/MANUAL_TRACING_GUIDE.md`, `docs/ANSWER_KEY.md`, UI → Manual tracing page |

| "Scan resistance" | Hot-plus-scan traces (`scanhot_h0.5C_s3C`, `scanhot_h0.5C_s10C`); pure scans included to show they give 0% for everyone; bar charts comparing policies | `traces/scanhot_*.txt`, UI → Results → Loops & scans tab |
| "Thrashing" | Loop traces at 0.90C, 1.00C, 1.10C, 1.25C; LRU gets 0% on loops > C while LIRS and BRRIP retain hits | `traces/loop_*.txt`, UI → Results → Loops & scans tab, capacity sweep in Results → Miss-ratio curves |
| "Zipfian locality" | Explanation of Zipf's law from zero with worked examples; traces across 8 alpha values showing how skew affects hit ratio | `docs/UNDERSTANDING.md` section 3, `traces/zipf_*.txt`, UI → Results → Lines tab (hit ratio vs alpha) |

## Suggested report outline

1. **Introduction** — what a cache replacement policy is, why misses are expensive, what this study adds.
2. **Methodology**
   - Simulator architecture and verification (cite test count and hand-verified badge).
   - Trace generation: bounded Zipf (why not `numpy.random.zipf`), scan/loop/extension families.
   - Sizing study: how we proved N = 600,000 is large enough.
3. **Algorithms** — one subsection per policy with data structures, a worked example table (export from the Manual tracing page), and expected behaviour per workload type.
4. **Results**
   - Summary table (export `summary.csv` from UI → Results → Export).
   - Heatmaps: alpha x working-set size per policy (export PNG from UI).
   - Hit ratio vs alpha line charts, one per working-set multiplier.
   - Loop and scan-resistance bar charts with OPT ceiling line.
   - Miss-ratio curves (capacity sweep).
   - Software vs hardware comparison with the SA-LRU fair-baseline caveat.
5. **Analysis**
   - Which policies win on which workloads, and why (wins table, average rank).
   - DRRIP below BRRIP on loops: the SRRIP-leader-set thrashing effect.
   - Adaptation over time: ARC p, CLOCK-Pro m_c, DRRIP PSEL.
6. **Manual tracing** — include 2-3 completed worksheet tables from `ANSWER_KEY.md`.
7. **Limitations** — synthetic traces, scaled-down cache, parameter sensitivity, OPT bypass convention.
8. **Conclusion**
